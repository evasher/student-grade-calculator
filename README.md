# student-grade-calculator
A simple Python program that calculates a student's total marks, average, and grade from five subjects.

## Features

- Takes the student's name
- Accepts marks for five subjects
- Checks that marks are between 0 and 100
- Calculates total marks
- Calculates the average
- Determines the student's grade
- Displays the results clearly

## Subjects

- Maths
- English
- Physics
- Biology
- Chemistry
